Qualimetry

Scenarios

Record browser actions with the extension, generate a Playwright test script, save the scenario here, and replay it as many times as you need.

1. Install the extension

Download qualimetry-extension.zip

  1. Unzip qualimetry-extension.zip somewhere you'll keep it.
  2. Open chrome://extensions (or your browser's equivalent).
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped qualimetry-extension folder.
  5. Pin the Qualimetry icon to your toolbar.

2. Record a scenario

Open the extension popup on the page you want to test, click Start recording, interact with the page normally, then click Stop & review, name the scenario, and Save. It's saved straight to this server.

3. Run it

Head to the Scenarios page to view saved scenarios, inspect the generated Playwright script, and replay a scenario as many times as you like — each run gets its own pass/fail report.
